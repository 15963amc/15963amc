# C++ 万年历项目（公元 1 年 ~ 3000 年）

这是一个使用 **C++17** 编写的命令行万年历项目，支持从公元 1 年到公元 3000 年的日期计算与月历打印。

## 一、功能设计

### 1) 日期合法性校验
- 校验年份范围：`1 <= year <= 3000`
- 校验月份范围：`1 <= month <= 12`
- 校验日范围：`1 <= day <= 当月最大天数`

### 2) 闰年判断
采用公历（Gregorian）规则：
- 年份能被 4 整除且不能被 100 整除，或
- 年份能被 400 整除

即：
```cpp
(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)
```

### 3) 查询某一天是星期几
- 输出范围：周一 ~ 周日
- 核心思想：把目标日期转换为“距离公元 1 年 1 月 1 日的总天数偏移”，然后对 7 取模

### 4) 打印某年某月月历
- 以周一为每周第一天
- 自动对齐首日位置
- 支持 1~3000 年任意年月

### 5) 查询某天是当年的第几天
- 通过“月份前缀和 + 当前日”快速计算
- 闰年且月份大于 2 时，额外 +1

## 二、实现方法说明

### 1) 核心类 `PerpetualCalendar`
封装以下能力：
- `isLeapYear(year)`：闰年判断
- `daysInMonth(year, month)`：返回某月天数
- `isValidDate(year, month, day)`：合法性检查
- `dayOfWeek(year, month, day)`：星期计算
- `dayOfYear(year, month, day)`：当年第几天
- `printMonthCalendar(year, month)`：打印月历

### 2) 星期计算公式
先计算从 `0001-01-01` 到目标日期前一天的总天数：

```text
days = daysBeforeYear(year) + daysBeforeMonth(year, month) + (day - 1)
```

其中：

```text
daysBeforeYear(year) = (year - 1) * 365
                     + (year - 1) / 4
                     - (year - 1) / 100
                     + (year - 1) / 400
```

该式含义：
- 普通年贡献 365 天
- 每 4 年一个闰日
- 每 100 年取消一个闰日
- 每 400 年恢复一个闰日

最后：

```text
weekday = days % 7
```

在本项目中定义：
- 0 = 周一
- 1 = 周二
- ...
- 6 = 周日

### 3) 月历打印对齐
- 先求当月 1 号的星期索引 `firstWeekday`
- 输出 `firstWeekday` 组空白占位
- 再逐日输出，满足 `(firstWeekday + day) % 7 == 0` 时换行

### 4) 复杂度分析
- 闰年判断：`O(1)`
- 星期查询：`O(1)`
- 当年第几天：`O(1)`
- 打印月历：`O(daysInMonth)`，最多约 31 次输出
